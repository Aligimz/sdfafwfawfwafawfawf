# ركن الهاتف — متجر هواتف كامل

متجر إلكتروني عربي لبيع الأجهزة الجديدة والمستعملة، الكفرات والحمايات، الاشتراكات (تليكرام بريميوم، نتفلكس، شاهد…) وبطاقات الشحن، مع لوحة إدارة وتتبع طلبات وتذكيرات تلقائية على تليكرام وواتساب.

## شنو بيه

**للزبون**
- أقسام: أجهزة جديدة، أجهزة مستعملة (مع وصف الحالة)، كفرات، اشتراكات، بطاقات، إكسسوارات
- بحث، فلترة حسب الماركة وجديد/مستعمل، ترتيب بالسعر
- صفحة منتج بصور متعددة وخيارات (سعة، لون، مدة، فئة) تغير السعر
- سلة وإتمام طلب بالدفع عند الاستلام، أجور توصيل حسب المحافظة
- رقم طلب وتتبع الحالة خطوة بخطوة
- ربط الطلب ببوت تليكرام حتى توصله التحديثات
- صفحة مراسلة وزر واتساب عائم

**للإدارة** (`/admin`)
- لوحة تحكم: مبيعات اليوم والشهر، مخطط 14 يوم، الأكثر مبيعاً، مخزون قليل
- المنتجات: إضافة وتعديل وحذف، رفع صور بالسحب، خيارات وأسعار، مخزون، إخفاء/إظهار، مميز
- الأقسام: إضافة أقسام جديدة بأي نوع
- الطلبات: تغيير الحالة مع إشعار الزبون، إرسال رسائل جاهزة (تأكيد، توصيل، كود تفعيل)، ملاحظات داخلية، سجل كامل، تصدير Excel
- الزبائن: كل زبون وعدد طلباته ومجموع شرائه
- الرسائل: الرد على واتساب
- التذكيرات: تلقائية ومخصصة، إرسال فوري، سجل الإرسال
- الإعدادات: معلومات المتجر، التوصيل، تليكرام، واتساب، المشرفين (مدير وموظف)

**التذكيرات التلقائية**
1. طلب ما انأكد خلال مدة تحددها (افتراضياً 60 دقيقة) ← تنبيه للإدارة
2. بعد التسليم بعدد أيام ← رسالة متابعة للزبون
3. قبل انتهاء أي اشتراك ← تذكير للزبون وللإدارة (المدة تنحسب من خيار "المدة": شهر، 3 أشهر، سنة)
4. أي تذكير مخصص تجدوله بنفسك لأي وقت

## التشغيل على جهازك

تحتاج Node.js نسخة 18 أو أحدث.

```bash
npm install
cp .env.example .env      # وعدّل كلمة سر المدير
npm start
```

- المتجر: http://localhost:3000
- لوحة الإدارة: http://localhost:3000/admin
- الدخول الافتراضي: `admin` / `change-me-now` ← **غيّرها أول شي** من الإعدادات

المنتجات الموجودة أول تشغيل أمثلة حتى تشوف الشكل. عدّلها أو احذفها من لوحة الإدارة وضيف منتجاتك وصورك.

## الرفع على الإنترنت

أي سيرفر يشغل Node.js يصير. الطريقة الأسهل والأرخص هي سيرفر VPS (مثلاً Hetzner أو DigitalOcean أو Contabo، تقريباً 5 دولار بالشهر):

```bash
# على السيرفر (Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash -
sudo apt install -y nodejs nginx
# ارفع مجلد المشروع للسيرفر، وبعدين:
cd rukn-store && npm install --omit=dev
cp .env.example .env && nano .env   # حط SITE_URL=https://دومينك و كلمة سر قوية و COOKIE_SECURE=true
sudo npm i -g pm2
pm2 start server.js --name rukn && pm2 save && pm2 startup
```

بعدها اربط الدومين بـ nginx واطلع شهادة https مجانية:

```nginx
server {
  server_name yourdomain.com;
  client_max_body_size 20m;
  location / { proxy_pass http://127.0.0.1:3000; proxy_set_header Host $host; proxy_set_header X-Forwarded-For $remote_addr; proxy_set_header X-Forwarded-Proto $scheme; }
}
```
```bash
sudo apt install -y certbot python3-certbot-nginx && sudo certbot --nginx -d yourdomain.com
```

**أو بـ Docker:**
```bash
docker build -t rukn-store .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data -v $(pwd)/uploads:/app/uploads --env-file .env --restart unless-stopped rukn-store
```

> ملاحظة: الاستضافات المجانية اللي تمسح الملفات عند إعادة التشغيل (مثل خطة Render المجانية) تضيّع قاعدة البيانات والصور. استخدم سيرفر بقرص دائم، أو اربط قرص (Volume) لمجلدي `data` و `uploads`.

**النسخ الاحتياطي:** كل بياناتك بملف `data/store.db` والصور بمجلد `uploads`. انسخهم بشكل دوري.

## ربط تليكرام (مجاني، 5 دقائق)

1. افتح [@BotFather](https://t.me/BotFather) وأرسل `/newbot` واختار اسم للبوت، راح يعطيك **توكن**
2. لوحة الإدارة ← الإعدادات ← تليكرام ← حط التوكن واحفظ
3. افتح البوت مالتك من حسابك وأرسل `/id`، راح يرد عليك برقم ← حطه بخانة "معرف محادثة المدير" واحفظ
4. اضغط "إرسال رسالة تجريبية"

بعدها:
- كل طلب جديد ورسالة توصلك على تليكرام
- أوامر للمدير بالبوت: `/orders` الطلبات المفتوحة، `/today` مبيعات اليوم
- الزبون بعد الطلب يشوف زر "تابع طلبك على تليكرام"، يضغطه وتوصله كل التحديثات والتذكيرات
- تكدر تحط معرف كروب بدل حسابك (أضف البوت للكروب وأرسل `/id` بالكروب) حتى يشوف الطلبات كل الفريق

## ربط واتساب (WhatsApp Cloud API)

واتساب الرسمي يحتاج حساب أعمال عند ميتا:
1. سوي حساب على [developers.facebook.com](https://developers.facebook.com) وأنشئ تطبيق من نوع Business وضيف منتج WhatsApp
2. اربط رقم هاتف خاص بالمتجر (رقم ما مستخدم بواتساب عادي)
3. انسخ **Permanent Access Token** و **Phone Number ID** وحطهم بالإعدادات
4. حط رقمك بخانة "رقم المدير" حتى توصلك التنبيهات

**مهم:** واتساب يسمح بالرسائل الحرة فقط خلال 24 ساعة من آخر رسالة بعثها الزبون. للتذكيرات (مثل انتهاء الاشتراك بعد شهر) لازم تسوي **قالب رسالة** وتنتظر موافقة ميتا:
- نوع القالب: Utility
- النص: `{{1}}` (أو مثلاً: `تنبيه من ركن الهاتف: {{1}}`)
- حط اسم القالب ولغته بالإعدادات، والموقع يحط نص التذكير مكان `{{1}}`

إذا ما ربطت واتساب، كل صفحة طلب ورسالة بيها زر "فتح بواتساب يدوياً" يفتح المحادثة من تلفونك والرسالة جاهزة.

## هيكل المشروع

```
server.js              نقطة التشغيل
src/db.js              قاعدة البيانات والإعدادات والبيانات الأولية
src/auth.js            تسجيل الدخول والجلسات
src/notify.js          إرسال تليكرام وواتساب ونصوص الرسائل
src/reminders.js       التذكيرات التلقائية والجدولة
src/telegramBot.js     بوت تليكرام (ربط الطلبات والأوامر)
src/routes/public.js   واجهة الزبائن البرمجية
src/routes/admin.js    واجهة الإدارة البرمجية
public/                واجهة المتجر
public/admin/          لوحة الإدارة
data/                  قاعدة البيانات (تنشأ تلقائياً)
uploads/               صور المنتجات
```

نسيت كلمة السر؟ من السيرفر:
```bash
npm run create-admin -- admin كلمة_سر_جديدة
```
